Aetherium
Ultra KEM

Complete formal specification of the Aetherium hybrid post-quantum key encapsulation mechanism: deterministic chaotic automaton, HKDF-SHA3-512 fusion, artifact integrity, and binding proofs. All formulas correspond to the reference Python implementation.

§ 1

Notations and Primitives

The following symbols are used uniformly throughout this specification.

$\mathcal{H}$
SHA3-512 hash function producing a 64-byte (512-bit) digest. All hash operations in Aetherium use SHA3-512 unless otherwise stated.
$\text{HKDF}$
HKDF key derivation function based on HMAC-SHA3-512 (extract-then-expand, RFC 5869 structure).
$\,\|\,$
Byte concatenation operator.
$\oplus$
Bitwise exclusive-or (XOR) operator, applied byte-by-byte.
$x \xleftarrow{\$} X$
Uniform random sampling of $x$ from the set $X$, via os.urandom.
$S[i]$
The $i$-th byte of state vector $S \in \{0,1\}^{512}$, for $i \in \{0,\dots,63\}$.
$\lfloor x \rfloor_t$
Truncation of $x$ to its first $t$ bytes.
$\langle r \rangle_4$
Big-endian serialization of integer $r$ on 4 bytes.
$R$
Number of automaton rounds. Fixed at $R = 64$.

§ 2

Deterministic Chaotic Automaton $E$

The automaton $E$ is a pure deterministic function that maps a public key $PK$ and a public seed $\varepsilon$ to a 512-bit final state $S_{\text{final}}$. No external entropy is consumed during evolution — the same $(PK, \varepsilon)$ always produces the same $S_{\text{final}}$.

Initial State def. 2.1

State initialization
$$ S_0 \;=\; \mathcal{H}\!\bigl(\varepsilon \;\|\; PK\bigr)\bigl[:64\bigr] \;\in\; \{0,1\}^{512} $$

The initial state is the first 64 bytes of $\mathcal{H}(\varepsilon \| PK)$. Since SHA3-512 produces exactly 64 bytes, $S_0 = \mathcal{H}(\varepsilon \| PK)$.

Evolution Loop def. 2.2

For each round $r \in \{0, 1, \dots, R-1\}$ with $R = 64$ :

  1. Deterministic noise generation
    Round noise
    $$ \eta_r \;=\; \mathcal{H}\!\bigl( \varepsilon \;\|\; PK \;\|\; \langle r \rangle_4 \bigr) \;\in\; \{0,1\}^{512} $$

    The noise is derived solely from public inputs and the round index — no clock, no PRNG state, no side-channel information.

  2. Intermediate hash
    State digest
    $$ h_r \;=\; \mathcal{H}\!\bigl( S_r \;\|\; PK \;\|\; \eta_r \;\|\; \langle r \rangle_4 \bigr) \;\in\; \{0,1\}^{512} $$
  3. Conditional XOR mutation

    Each byte of the state is conditionally XORed with the corresponding byte of $h_r$, controlled by the parity of $\eta_r$ :

    Byte mutation rule
    $$ S_{r+1}[i] \;=\; \begin{cases} S_r[i] \;\oplus\; h_r[i] & \text{if } \eta_r[\,i \bmod 64\,] \;\&\; 1 \;=\; 1 \\[6pt] S_r[i] & \text{otherwise} \end{cases} \quad \forall\, i \in \{0,\dots,63\} $$

    The least significant bit of $\eta_r[i \bmod 64]$ determines whether byte $i$ is mutated. On average, half of the 64 bytes are modified per round.

Final State def. 2.3

Automaton output
$$ \boxed{\; S_{\text{final}} \;=\; E(PK,\, \varepsilon) \;=\; S_R \;=\; S_0 \xrightarrow{\;(\eta_0, h_0)\;} S_1 \xrightarrow{\;(\eta_1, h_1)\;} \cdots \xrightarrow{\;(\eta_{63}, h_{63})\;} S_{64} \;\in\; \{0,1\}^{512} \;} $$
Determinism property: $E$ is a pure function. Given the same $(PK, \varepsilon)$, any party can independently compute the same $S_{\text{final}}$. This is the foundation of the decapsulation verification in §4.
§ 3

Encapsulation — $\text{Encapsulate}(PK_{\text{rec}})$

The sender generates a public artifact $\mathcal{A}$ and a secret session key $K_{\text{final}}$ for the recipient holding public key $PK_{\text{rec}}$.

  1. Sample public seed $$\varepsilon \;\xleftarrow{\$}\; \{0,1\}^{512}$$
  2. Compute chaotic state $$S_{\text{final}} \;=\; E(PK_{\text{rec}},\; \varepsilon) \;\in\; \{0,1\}^{512}$$
  3. KEM encapsulation (ML-KEM-1024)
    Post-quantum KEM
    $$ \bigl(C_{\text{kyber}},\; SS_{\text{kyber}}\bigr) \;=\; \text{KEM.Enc}(PK_{\text{rec}}) $$

    $C_{\text{kyber}}$ is the KEM ciphertext (variable length). $SS_{\text{kyber}}$ is the shared secret. When pqcrypto is unavailable, a deterministic HMAC-based stub provides the same interface for testing purposes.

  4. Session key derivation (HKDF fusion)

    The KEM shared secret and the chaotic state are fused into a single session key :

    Key material
    $$K_{\text{mat}} \;=\; SS_{\text{kyber}} \;\|\; S_{\text{final}}$$
    Session key
    $$ \boxed{\; K_{\text{final}} \;=\; \text{HKDF}\!\bigl( \text{salt} = \mathcal{H}(PK_{\text{rec}}),\; \text{ikm} = K_{\text{mat}},\; \text{info} = \texttt{"aetherium-v1"},\; \text{len} = 64 \bigr) \;\in\; \{0,1\}^{512} \;} $$

    The salt is $\mathcal{H}(PK_{\text{rec}})$, binding the key derivation to the recipient's identity. The IKM concatenates both secrets, ensuring $K_{\text{final}}$ depends on both layers.

  5. Binding proof $\Sigma$
    Binding proof
    $$\Sigma \;=\; \mathcal{H}\!\bigl(K_{\text{final}} \;\|\; S_{\text{final}} \;\|\; C_{\text{kyber}}\bigr) \;\in\; \{0,1\}^{512}$$

    $\Sigma$ binds the session key to the artifact contents. Without $K_{\text{final}}$, an attacker cannot forge a valid $\Sigma$.

  6. Integrity tag $C$
    Truncated integrity tag
    $$C \;=\; \lfloor\, \mathcal{H}\!\bigl(C_{\text{kyber}} \;\|\; S_{\text{final}} \;\|\; \Sigma \;\|\; \varepsilon\bigr) \,\rfloor_{32} \;\in\; \{0,1\}^{256}$$

Artifact Structure def. 3.1

The transmitted artifact is the tuple :

Transport artifact
$$\mathcal{A} \;=\; \bigl(\, C_{\text{kyber}},\; S_{\text{final}},\; \Sigma,\; C,\; \varepsilon \,\bigr)$$
FieldSizeRole
$C_{\text{kyber}}$variablePost-quantum KEM ciphertext

§ 4

Decapsulation — $\text{Decapsulate}(SK_{\text{rec}}, PK_{\text{rec}}, \mathcal{A})$

The recipient uses their secret key $SK_{\text{rec}}$ and public key $PK_{\text{rec}}$ to recover the session key $K_{\text{final}}$ from the artifact $\mathcal{A}$, or reject with $\bot$ if any verification fails. All comparisons use constant-time hmac.compare_digest.

  1. Integrity verification
    Recompute tag
    $$C' \;=\; \lfloor\, \mathcal{H}\!\bigl(C_{\text{kyber}} \;\|\; S_{\text{final}} \;\|\; \Sigma \;\|\; \varepsilon\bigr) \,\rfloor_{32}$$
    $$\text{If } C' \;\neq\; C \;\Longrightarrow\; \bot \quad \text{(artifact tampered or replayed)}$$
  2. KEM decapsulation
    Recover shared secret
    $$SS_{\text{kyber}} \;=\; \text{KEM.Dec}(SK_{\text{rec}},\; C_{\text{kyber}})$$
    $$\text{If KEM.Dec fails} \;\Longrightarrow\; \bot \quad \text{(wrong SK or corrupted ciphertext)}$$
  3. Automaton state verification

    The recipient independently recomputes the automaton state from the public seed :

    Recompute automaton
    $$S'_{\text{final}} \;=\; E(PK_{\text{rec}},\; \varepsilon)$$
    $$\text{If } S'_{\text{final}} \;\neq\; S_{\text{final}} \;\Longrightarrow\; \bot \quad \text{(PK mismatch or corrupted artifact)}$$
    Correctness: Since $E$ is a pure function, the recipient's $S'_{\text{final}}$ is identical to the sender's $S_{\text{final}}$ when computed with the same $PK$ and $\varepsilon$. This step detects any corruption of $S_{\text{final}}$ or $\varepsilon$ in transit, and confirms that the artifact was built for this specific recipient.
  4. Session key reconstruction
    Key derivation
    $$ K'_{\text{final}} \;=\; \text{HKDF}\!\bigl( \text{salt} = \mathcal{H}(PK_{\text{rec}}),\; \text{ikm} = SS_{\text{kyber}} \;\|\; S'_{\text{final}},\; \text{info} = \texttt{"aetherium-v1"},\; \text{len} = 64 \bigr) $$
  5. Binding proof verification
    Verify Sigma
    $$\Sigma' \;=\; \mathcal{H}\!\bigl(K'_{\text{final}} \;\|\; S'_{\text{final}} \;\|\; C_{\text{kyber}}\bigr)$$
    $$\text{If } \Sigma' \;\neq\; \Sigma \;\Longrightarrow\; \bot \quad \text{(key-commitment attack detected)}$$

    This final check ensures that the session key is consistent with the entire artifact. An attacker who modifies $C_{\text{kyber}}$ after integrity passes (e.g. via tag collision) would still fail this check because the binding proof includes $K_{\text{final}}$.

Output def. 4.1

Decapsulation result
$$ \boxed{\; \text{Decapsulate}(SK_{\text{rec}}, PK_{\text{rec}}, \mathcal{A}) \;=\; \begin{cases} K'_{\text{final}} \;\in\; \{0,1\}^{512} & \text{if all 5 checks pass} \\[6pt] \bot & \text{otherwise} \end{cases} \;} $$
§ 5

Security Properties

Hybrid Security Argument prop. 5.1

$K_{\text{final}}$ is computed as $\text{HKDF}(SS_{\text{kyber}} \| S_{\text{final}})$. To recover $K_{\text{final}}$, an adversary must obtain both :

Attack requirements
$$ \begin{aligned} &\text{(a)}\quad SS_{\text{kyber}} &&\text{requires breaking ML-KEM-1024 (NIST Level 5)} \\ &\text{(b)}\quad S_{\text{final}} &&\text{is public, but without } SS_{\text{kyber}} \text{, HKDF output is indistinguishable from random} \end{aligned} $$

If ML-KEM is IND-CCA2 secure and HKDF is a secure KDF, then knowledge of $S_{\text{final}}$ alone provides no advantage in recovering $K_{\text{final}}$. The chaotic automaton provides an additional security margin: even if the KEM has a partial weakness, the attacker must also handle the HKDF fusion with the automaton state.

Artifact Integrity prop. 5.2

The tag $C = \lfloor \mathcal{H}(C_{\text{kyber}} \| S_{\text{final}} \| \Sigma \| \varepsilon) \rfloor_{32}$ covers all artifact fields. Any modification to any field changes $C'$ with overwhelming probability (collision resistance of SHA3-512).

Binding Proof prop. 5.3

$\Sigma = \mathcal{H}(K_{\text{final}} \| S_{\text{final}} \| C_{\text{kyber}})$ binds the session key to the artifact. An attacker cannot produce a valid $\Sigma$ without knowing $K_{\text{final}}$, which requires the private key $SK_{\text{rec}}$. This prevents key-commitment and key-substitution attacks.

Timing Resistance prop. 5.4

All equality checks in decapsulation use hmac.compare_digest (constant-time), preventing timing side-channel attacks on the tag, the automaton state, and the binding proof.
